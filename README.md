# 魔精小宠

Windows 桌面小宠物「魔精小宠」。桌宠默认显示在桌面右下角，右键桌宠可以打开功能菜单。

## 直接运行

发布版位于 `发布版` 目录：

- `魔精小宠_v1.0.0.exe`：带版本号的发布文件，适合分享。
- `魔精小宠.exe`：稳定启动入口，适合桌面快捷方式。

单文件程序已经包含运行所需的图片和 Python 依赖。首次运行时，程序会在 exe 所在目录生成统计数据和布局文件。

## 发布内容

本公开仓库只提供 Windows 单文件发布版。源码和开发资源保存在独立的私有仓库中。

## 使用方式

双击 exe 启动程序，右键桌宠可以打开功能菜单。程序会记录键盘和鼠标敲击数，并提供气泡、提醒、缩放和开机启动设置。

## 数据文件

程序运行后会生成：

- `desktop_pet_data.json`：统计数据和提醒状态。
- `desktop_pet_layout.json`：桌宠、气泡的位置和缩放设置。

这些文件已加入 Git 忽略规则，不会把本机数据提交到仓库。

## 版本

当前版本为 `v1.0.0`。每次发布更新时递增版本号，并同时更新 `发布版/版本号.txt`。
