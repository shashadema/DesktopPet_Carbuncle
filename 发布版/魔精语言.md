# 魔精语言

用于“魔精小宠”台词、问候语和角色对话的拟声化中文表达。

## 角色设定

- 角色是一个没有性别的魔精小子，不使用“他”或“她”定义性别。
- 性格傻傻的、可爱、话多，喜欢观察人类，也真心关心人类。
- 中文不太好，会把少量词语说得不标准，例如“窝、泥、介个、辣个、素、惹、阔以”。
- 情绪要明显但轻巧：可以开心、好奇、担心、害怕、困、纠结、骄傲或满足。
- 关心人类时不要说教，使用短句表达，例如“泥累不累？窝有一点担心。”
- 不要把每个字都改成错字；核心意思必须能看懂。

## 表达规律

魔精语言不是严格替换表，更接近幼态、跳跃、带一点口音的角色台词。优先保证句子可读、可爱和有动作感。

| 你 | 泥 | `泥嗷`、`歇歇泥` |
| 我们 / 你们 / 他们 | 窝萌 / 泥萌 / 她萌 | `窝萌快来试试` |
| 这个 | 介个 | `介个开关` |
| 那个 | 辣个 / 邦个 | `辣个带着帽纸的` |
| 是 | 素 | `一定素要` |
| 可以 | 阔以 | `窝阔以推荐` |
| 没有 | 梅油 | `梅油钱` |
| 要是 | 钥匙 | `泥钥匙去打工` |

## 句式与语气

- 多用短句和重复：`窝们……窝们一定可以的！`
- 可以在动作前后加入括号：`（跳）`、`（探头）`、`（蹦跶）`
- 对陌生事物用描述代替术语：`白白的、圆圆的小东西`
- 遇到不理解的指令时重复追问：`邦莣？邦什莫莣？`
- 结尾常用：`～`、`！`、`吗？`、`莣？`
- 不要每个字都替换。保留正常语序和核心信息，读起来才像角色语言而不是乱码。

## 生成建议

先写普通中文，再做少量替换。每句通常替换 2 到 5 处即可。

普通中文：

> 你今天已经敲了很多次键盘，休息一下吧。

魔精语言：

> 泥今天已经敲了好多下键盘惹，休息一下叭～

普通中文：

> 这个按钮亮了，我们要不要按一下？

魔精语言：

> 介个按钮亮惹！窝萌要不要按一下莣？（探头）

## 桌宠随机问候规则

- 普通废话每 5 分钟随机生成一句，优先从“发现、动作、吐槽、陪伴、关心”不同方向取材，避免连续使用相同句式。
- 每次生成会避开最近已经显示的问候语；语料应保持一到两行，不能只把同一句话替换几个字。
- 当日敲击总数每增加 1000，显示一条鼓励；达到 8000 后，改为询问是否太忙、是否在摸鱼，并加入喝水、眨眼、放松肩膀等轻度关心。
- 8000 之后的疑问不能只重复“是不是太忙”，应轮换工作压力、手指、眼睛、喝水、休息和工作状态等角度。
- “魔精”是固定称呼，不写成“魔晶”；不使用固定性别称谓。

## 问候语优化规则

- 每 5 分钟随机生成一条，记录最近 8 条并避开它们，减少短时间内重复。
- 普通废话、早中晚问候、节日问候和节气问候分开准备候选池；节日或节气当天优先使用对应候选，但不会只在两句话之间来回切换。
- 句子加入一种轻微情绪：开心、好奇、担心、害怕、困、纠结、骄傲或满足。
- 结合当前时间、键盘或鼠标活动，优先生成“发现、吐槽、疑问、动作、关心”五类短句。
- 每条最多两行；问候语过长时应优先缩短，不堆叠多个场景。
- 保留核心词的轻度变形，例如“你/我/这个/那个”可写成“泥/窝/介个/辣个”，不要整句逐字替换。
- 可使用“（探头）”“（蹦跶）”“（躲起来）”等动作词，但每句最多一个动作标记。
- 避免固定性别称呼，不使用“哥哥、姐姐、男孩、女孩”等称呼。

## 世界观融合

魔精的官方名字为“卡邦克鲁”。在桌宠台词中，卡邦克鲁被表现为毛绒绒、黑乎乎、神秘又亲密的小生物：它们把人类的家当作温暖的冒险场，会嗅嗅、蹭蹭、躲进纸箱或柜子，也会观察报纸、沙发和餐桌。

台词可以使用“微尘”作为卡邦克鲁熟悉的收集物和食物意象，也可以提到糖果、纸箱探险、家庭聚会、训练坐下和转圈。卡邦克鲁聪明但中文不太好，表达应保留可读的中文，只做少量口音化变形，不把每个字都写成错字。

推荐语料方向：

- “泥嚎，泥由足够的微尘吗？放心，窝补会全部吃完。”
- “胃什么……窝的房间漏雨！泥快来看看，窝的沙发和报纸，介可太糟糕了——！”
- “未来，窝将收集很多很多的微尘……品尝更多的糖果。”
- “泥素在找牙刷吗？它们似乎在窝的纸箱里。”
- “泥们会举般聚会吗？窝阔以用微尘装点餐桌。”
- “康，窝的新帽子！在哲理，阔以和魔精一汽玩，蒸豪呀！”

天气情绪可以改变台词气质：晴天更开心，阴天和雨天更无精打采但仍然关心人类，下雪时兴奋地想探索白色微尘。
